# 3D 자산 실험의 출처

2026-10-07: 외부 3D 자산을 제품 슬롯으로 사용하는 예제. npm 패키지에 포함하지 않는다.
원본은 수정하지 않았으며 각 파일은 500×500 투명 PNG다. 파일을 CDN에서 매번 가져오면
오프라인·네트워크 실패가 공통 UI 검증과 섞이므로 Showcase에 두 파일만 보존한다.
전체 아이콘 라이브러리나 premium 변형은 포함하지 않는다.

저자: Vijay Verma / 3dicons. 원본 상세의 CC0 표시를 확인하고 실제 그림(노트·체크)을 열어 대조했다.
아래 제목이 의미를 전달하므로 그림은 장식이다. 그림 실패 시에도 제목·다음 행동은 남는다.
제품은 자신의 자산·문구를 공급하며 이 예제의 색·그림을 기본 브랜드로 복사하지 않는다.

미리보기 WebP는 흰 배경이 합성되어 다크 테마에서 사각형이 드러났다. 원문 UI의
Download current(dynamic/color, 500x500)로 받은 투명 PNG로 교체했다. 배경을 임의 편집하지 않았다.
