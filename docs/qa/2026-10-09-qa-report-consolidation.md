# HJM 조사·실험 QA 참조와 미커밋 통합

## 판정과 대상

문서 범위 통과. 2026-10-09 00:35~00:39 KST, Codex. main
`24bc24d2ce145dd25e11b1ff5e88d73209bc6dfb`와 공유 checkout의 기존 QA 정리 상태를 확인했다.
HJM 실험 8개 승격·1.16.0 게시와 후속 1.17.2 게시 기록은 기존 제품 도입 리포트에 있다.
이번 변경은 새 실험 구현·package source·버전·native runtime을 바꾸지 않는다.

## 문제와 수정

공유 checkout에는 원시 조사 JSON 4개와 이미지 45개의 삭제가 미커밋으로 남아 있었다.
문서 검사는 12개 문서의 56개 참조가 삭제된 파일을 가리켜 실패했다. 삭제를 되돌려
원시 산출물을 다시 보관하는 대신, 이미지 설명은 해당 리포트의 텍스트 결과와 연결하고
JSON 원장은 A/B/C의 Markdown 조사 요약·미확인 범위로 연결했다.
과거 원장·이미지 보존 문구와 현재 보관 상태를 구분하는 날짜 주석을 추가했다.

실측 수·원제품 관찰·실패·판정·전수 미완료 범위는 유지한다. 개별 URL 원시 레코드 전체를
리포트에 덤프하거나 삭제된 원장을 현재 조회 가능한 증거로 표시하지 않는다.
새 사이트 조사·화면/접근성·기기 재검증을 수행한 것으로 보고하지 않는다.
기존 미커밋 개발 클라이언트 설치 리포트도 당시 SHA·실물 기기·설치/실행과 화면 미검증
경계를 그대로 보존해 통합한다. 그 리포트의 빌드·설치 성공을 이번에 재확인한 것은 아니다.

## 검사와 환경

macOS, Node24.20.0. 설치·빌드·시뮬레이터·Metro 변경 없이 문서만 검사했다.
수정 전 `node scripts/check-doc-links.mjs`는 LINK_TARGET_MISSING 56건으로 exit1.
수정 후 같은 명령은 문서 링크 통과, `git diff --check`도 통과했다.
최종 재실행은 이 리포트를 포함한 598 Markdown 문서 통과다.
`module.contract.json`은 삭제 대상 QA 경로를 참조하지 않으며
governance/acceptance의 `docs/evidence`와 source·회귀 fixture는 수정하지 않았다.

HJM 기기/실물 QA·소비 앱 전체 도입·운영 배포·OTA 적용은 이번 변경의 검사 범위가 아니다.
