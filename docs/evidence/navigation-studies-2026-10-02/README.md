# 내비게이션 바 실험 — 2026-10-02

사용자 요청: Instagram의 내비게이션 바를 흡수하고 별도 탭에서 확인한다.
참고: https://www.instagram.com/p/Dd9IBiPFmI_/?img_index=7

브라우저에서 표지와 10개 앱 구성 이미지를 직접 확인했다. 선택 슬롯·중앙 액션·분리 액션·브랜드
대비를 기존 BottomNavigation, IconButton, Provider 조합으로 표현했다. Iconly 에셋은 복사하지
않고 기존 Lucide를 사용한다. 전체가 쇼케이스 실험이며 공개 API·제품 기본값은 바뀌지 않는다.

- `실험/내비게이션 바/전체 비교`: 신규 10종과 기존 기본·floating·capsule·글래스 구성.
- 개별 10종: 기본·어두운 테마·큰 글자. Web/Native에 동일 분류 등록.
- 중앙 액션은 `center-gap`으로 영역을 예약하고, 선택 상태와 실행 횟수는 독립 관리.
- 작은 화면·큰 글자에서는 원본의 아이콘 전용 표현보다 목적지 이름과 조작 가능성을 우선한다.
- 원본은 정적 이미지다. 원제품의 애니메이션·탐색 흐름·전환 효과를 확인했다고 주장하지 않는다.
- 웹은 실제 목적지 링크와 현재 위치 표시를 유지한다. 예제 목적지는 문서 내부 hash이며 실제
  제품 라우트·장바구니·전원·저장 API는 연결하지 않았다.

검증: Web showcase check (타입·28개 검사·토큰 경계), Native showcase check
(스토리 등록·타입·12개 검사) 통과. 390px 웹 캡처 확인. Native 실기기 검증·패키지 게시·소비 앱
배포는 수행하지 않았다. 분류 승격은 사용자 승인 전이다.

추가 브라우저 검증: 320px에서 10종 × 3상태(30개)의 두 번째 목적지를 실제 클릭해
`aria-current=page` 전환, 가로 넘침 없음, pageerror 없음 확인. 첫 검사에서 중앙 액션이
목적지 위를 덮어 클릭을 막았으므로 compact 밀도와 쇼케이스 내부 중복 수평 여백 제거로
수정하고 30개 전체를 다시 통과시켰다. 외부 제품의 기본 레이아웃 정책 변경은 아니다.
