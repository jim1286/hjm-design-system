# Storybook 단계 정리 · 2026-10-02

사용자 요청: 배포와 실험 양쪽에 토큰 → 컴포넌트 → 구성 → 화면을 적용하고 승인 후 이동을
스토리북 배포라고 부른다. 내비게이션 바만 배포 분류로 이동하며 상호작용 예제는 실험에 유지한다.

- Web/Native 230개 스토리 파일을 역할에 맞게 재배치했다. Web CSF id는 보존했다.
- Web 정적 색인 352개 항목: 배포 토큰 9, 컴포넌트 263, 구성 38, 화면 23, 실험 구성 19.
  스토리와 문서를 합친 수이며 컴포넌트 API 수를 의미하지 않는다. 비어 있는 실험 단계는 자리 채우기로 만들지 않았다.
- 내비게이션의 10개 표현을 4개 기능별 메뉴에 모으고 중복 6개와 캡슐 예제 등록을 제거했다.
- Web 타입 검사·28개 테스트·토큰 경계 검사·정적 빌드·103개 canonical 및 13개 안내 항목 검사 통과.
- Native 목록 생성·타입 검사·13개 테스트 통과. 기기 UI 확인은 수행하지 않았다.
- 320px Web에서 새 흐름 3개 × 기본/어두운 테마/큰 글자 9개와 내비게이션 4개 그룹을 조작했다.
  적용/취소·닫기 후 focus 복귀·초안 복원·역순 응답 무시를 확인했다. 가로 넘침과 pageerror 없음.
- npm 게시·소비 제품 업데이트·원격 Storybook 게시·앱 출시는 수행하지 않았다.

## 후속 지침과 리퀴드 토스트 · 2026-10-02

[상호작용 품질 기준](../../INTERACTION_QUALITY.md)에 구현된 6개 실행·복구/입력 예제와
내비게이션·선택적 adapter를 연결했다. README, AGENTS, CONTRIBUTING, 저작·소비 지침,
상호작용·Expo 문서와 포트폴리오 개발·웹앱·DESIGN 템플릿을 최신화했다.

리퀴드 토스트는 기본 원형 32×32, 카드 반경 16으로 수정하고 RN 내용 clipping과 Skia 표면의
반경을 맞췄다. 계약 3개·Native 표현 7개 테스트, Native 타입·빌드, 계약 동기화와 문서 검사를
통과했다. 이전 동영상은 예전 모양이며 이번 모양의 기기 화면·Release 프레임 성능은 미검증이다.
웹은 기존 일반 토스트 대체 표시이며 리퀴드 애니메이션을 추가하지 않았다. 게시·앱 이관은 수행하지 않았다.
