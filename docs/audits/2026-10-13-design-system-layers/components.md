# 컴포넌트 전수 정적 감사와 수정

판정: **부분 확인**. 140개 지침 전체를 파일 본문으로 로드해 공개 이름·import·예제 JSX·버전 문구·지원 표기를 전수 대조했다. 모든 컴포넌트의 모든 상태를 실행한 것은 아니며, 전 문장의 수동 정독이나 모든 renderer 분기 검증을 완료했다고 주장하지 않는다. 목적/함정 부분은 전 항목을 검토하고, 아래 결함의 본문·구현·회귀를 집중 확인했다.

- 대상: main, 시작 HEAD `767d47f7`, 2026-10-13의 공유 working copy. 시작부터 Toast·BottomNavigation·Carousel·화면·dist 등에 다른 작업의 미커밋 변경이 있었다. 그 변경을 보존했다.
- 범위: `usage/components/*.md` 140개. 공개 API 대응표는 Web 163개 + Native 149개 = 312개 renderer export를 포함한다. canonical 외 supplemental·companion·optional도 포함했다.
- 정적 검사: TypeScript checker가 각 312개 공개 함수의 call signature/props를 해석했고, 지침의 JSX 364개 사용·직접 속성 1,346개를 대조했다. import·prop 이름 불일치 미발견. 문자열 literal 검사에서 나온 Native Skeleton `width="60%"`는 허용된 template literal 타입을 단순 검사기가 오인한 것으로 판별했다. 이것은 예제 파일 전체의 tsc 통과가 아니다(제품 변수·콜백·spread 내용은 별도).
- package exports의 실제 dist 대상 파일 존재: Web 101 entry·Native 85 entry 모두 존재. 존재를 source/dist 동등성·실제 npm artifact·기기 확인으로 확대하지 않았다. source만 수정했고 빌드·dist 갱신·설치·게시·소비 앱 반영은 하지 않았다.
- 최대 OS 글자 및 이를 모사하는 검사는 제외했다. 신규 레포·브랜치·worktree·임시 파일은 만들지 않았다.

## 남은 경계

- 전체 140개의 목적·지원·공개 API/예제는 대조했지만, 모든 prop 조합·layout 숫자·지원 host 동작·CSS 계산 결과를 실행하지 않았다. 아래 미발견은 이 정적 범위에 한한다.
- deprecated Native style 호환 prop은 실제 source에 남아 있다. 지침을 삭제해 API가 사라진 것처럼 만들지 않았다. 제거는 소비 경로 조사·migration·SemVer를 함께 다루는 변경이어야 한다.
- optional Native peer 설치·링크·기기 host/키보드/OS picker·성능은 미검증이다. 타입 signature가 있다고 동작한다고 판정하지 않는다.
- screens.tsx/screen-flows.tsx 및 화면 구성 변경은 부모 담당이다. 이 표의 화면 컴포넌트는 import/props·관련 낡은 문구만 다루며 부모 보고서와 함께 읽는다.
