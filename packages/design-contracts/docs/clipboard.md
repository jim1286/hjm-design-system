# ClipboardButton

복사는 제품이 반복해서 다시 만들던 세 가지다: 비동기 clipboard 호출, 잠깐 보이는 "복사됨"
상태, 그리고 **그 상태를 읽어 주는 것**.

마지막 하나가 늘 빠졌다 — 라벨이 눈에만 바뀌면 보조기기 사용자는 아무 일도 일어나지
않은 것과 같다. 그래서 `role="status"`로 함께 알린다.

- **거부된 클립보드를 성공으로 속이지 않는다.** 권한이 없으면 `onCopyError`로 알리고
  라벨은 그대로 둔다.
- **값이 바뀌면 "복사됨"을 지운다.** 그 표시는 이전 문자열을 가리키던 것이라, 남겨 두면
  사실이 아닌 말을 화면에 두는 셈이다.
- 두 상태의 문구는 제품이 준다.
