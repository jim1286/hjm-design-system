ScreenLayout accepts `titleLeading`, a decorative identity mark (team logo, tool artwork) before the centered or start title; with `titleVisibility="hidden"` the mark stands alone as the heading named by `title`. It also accepts `loadingIndicator`, the same brand loading visual CompositionLayout takes, while the shared state keeps its accessible name and centering.
